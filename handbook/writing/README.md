# 작성 안내

이 문서는 사이트에 배포하지 않는 편집 지침이다. 공개 저장소에서는 읽을 수 있다.

먼저 [공통 문체](voice.md)를 읽고 페이지별 가이드를 적용한다: [Home](home.md), [Blog](blog.md), [About](about.md), [Papers](papers.md), [Work](work.md), [서브앱](spaces.md).

## 편집 순서

1. 작성자가 제공한 사실, 경험, 의견, 사진, 출처를 모은다.
2. 페이지 목적과 글 종류를 정한다. 아래 가이드의 원문 표본을 실제로 읽는다.
3. 템플릿의 대괄호를 확인된 정보로 채운다. 없는 정보는 지어내지 않는다.
4. 기존 글을 수정한다면 주장, 확신의 정도, 날짜를 바꾸지 않았는지 diff를 확인한다.
5. `npm run check && npm run build && npm test`를 실행하고 8081에서 모바일/데스크톱을 확인한다.
6. AI 초안은 작성자가 검토한 뒤 발행한다. 가이드는 문체의 근사이지 본인 검수의 대체물이 아니다.

## AI에게 전달할 지침

> handbook/writing/voice.md와 대상 페이지 가이드를 먼저 읽어라. 원문 표본과 제공된 사실에 근거해 초안을 작성하라. 직접 경험, 인용, 수치, 감정, 성과를 발명하지 마라. 책 저자의 주장과 작성자의 의견을 분리하라. 미확정 정보는 질문 목록으로 본문 밖에 남겨라. 기존 글을 임의로 교정하거나 마케팅 문구로 바꾸지 마라. 사용한 근거와 편집한 범위를 초안 밖에 간단히 기록하라.

## 사실 확인 원칙

- About의 직함, 연락처, 주소와 Work의 `~` 표기 항목이 현재도 유효한지 본인 확인이 필요하다. 확인되지 않은 값은 추정하여 변경하지 않는다.
- 기존 이미지의 `alt` 같은 일반적인 대체 텍스트는 원본 정보가 부족하다. 사진을 확인하지 않고 설명을 발명하지 않는다.
- 과거 블로그의 Svelte 관련 설명은 당시의 기록이므로 현재 Astro에 맞춰 소급 수정하지 않는다.
