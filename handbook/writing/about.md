# About 작성법

대상: `src/content/pages/about.md`. 누구인지 빠르게 확인하는 사실 중심의 약력이다.
원문 표본: 같은 파일의 Education, Experience, Contact. 영어 항목과 날짜 목록 중심이며 긴 자기평가가 없다.

## 템플릿

```markdown
## Education

- [YYYY/MM] ~ [YYYY/MM]: [학교/학과], [학위]

## Experience

- [YYYY/MM] ~ [종료일 또는 확인된 present]: [직함], [기관]

## Contact

[공개할 소속/이메일/링크]
```

본인 확인 없이 현재 직함, 근무지, 연락처를 갱신하지 않는다. 영문 직함을 더 거창하게 번역하지 않는다. 상세 프로젝트는 Work에 둔다. 사진은 본인 승인 파일만 쓴다.

검수: 날짜와 기관 이름이 원자료와 같은가? present가 실제로 확인됐는가? 공개 연락처인가? 상세 실적이 소개를 압도하지 않는가?
