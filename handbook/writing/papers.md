# Papers 작성법

대상: `src/content/pages/papers.md`. 기존 파일의 논문 서지 표기를 먼저 읽는다. 감상이나 홍보보다 정확한 목록이 목적이다.

## 항목 템플릿

```markdown
- [저자들을 출판물 순서대로], "[정확한 논문 제목]," [저널/학회], [권/호/페이지 또는 논문번호], [연도]. [DOI](https://doi.org/[확인된 DOI])
```

원문에 없는 권호/DOI/피인용수는 만들지 않는다. 저자 순서, 제목 대소문자, 학술지명은 출판물 기준이다. 미출판/게재 승인/출판 완료는 확인 후 구분한다. 기존 섹션과 정렬을 유지하고 새로운 분류가 필요하면 먼저 합의한다. 논문 소개를 덧붙인다면 독립된 Blog 글로 작성한다.

검수: 출판사 페이지와 일치하는가? 링크를 확인했는가? 공개 PDF의 배포 권한이 있는가? 본인 기여를 과장하지 않았는가?
