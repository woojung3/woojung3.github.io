# 독립 페이지 작성법

돌잔치 원문 표본: `public/spaces/juha/index.html`. "이주하의 첫돌", "돌잔치에 초대합니다"처럼 목적과 사실이 먼저 나온다. 블로그의 평서체를 초대장에 강요하지 않는다.

## 초대장 템플릿

```text
[행사 이름]
[짧은 초대 문구]
[확인된 날짜, 요일, 시간]
[장소와 지도]
[안내/연락처: 공개 가능한 범위]
```

여행 일정표는 날짜 -> 시간 -> 장소 -> 이동/예약 메모 순서로 구성한다. 확인된 일정과 후보를 구분하고 AI가 예약 확정이나 운영시간을 추정하지 않는다.

## 기술 구조

- 기존 돌잔치는 독립 정적 앱으로 보존한다. 본체 CSS/JS를 상속하지 않는다.
- 새 앱은 `src/pages/spaces/<name>/`에 만들고 독립 레이아웃을 사용한다. 작은 데이터는 앱 옆에 두며 전역 상태로 올리지 않는다.
- 숨김 앱에는 noindex를 설정하고 공개 목록/RSS/사이트맵에 추가하지 않는다. 자체 OG 제목/설명/이미지를 제공한다.
- 퍼즐은 접근 통제가 아니다. 공개하면 안 되는 일정/사진/키는 저장소에 넣지 않는다.
- 조작은 터치/키보드에서도 가능해야 한다. hover 전용 해답을 만들지 않는다.

검수: 날짜/요일/지도 주소 일치, 공유 미리보기, 모바일 스크롤, 인쇄가 필요한 문서의 인쇄 화면, 개인정보 노출 여부를 확인한다.
